# Classification Model Training

This project demonstrates a machine learning classification workflow using Python and Scikit-learn.

## Work Performed

1. Imported the dataset and required Python libraries.
2. Cleaned and preprocessed the data.
3. Checked and handled missing values.
4. Prepared the data for machine learning.
5. Split the data into training and testing sets.
6. Applied the Decision Tree algorithm.
7. Trained and evaluated the Decision Tree model.
8. Selected Random Forest for classification.
9. Trained the Random Forest model.
10. Evaluated the model using accuracy and confusion matrix.

## Model Used

- Decision Tree
- Random Forest

## Result

The Random Forest model achieved **100% accuracy** on the test data.
